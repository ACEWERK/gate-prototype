# gate-prototype

Interactive prototype of Gate's stablecoin checkout (v2). It is a single self-contained `index.html` that makes no network requests. Open it in a browser.

- **Buyer checkout:** choose a payment method, enter your details, then send payment. The FX quote has a live 1-hour countdown.
- **Presenter controls:** four scenarios (Default, Provide additional information, Rejected, Refunded) plus Reset. Each scenario restarts the flow with demo data prefilled. Every step runs from a labelled on-screen control, including the in-prototype email viewer.
- **Design notes:** regulatory and design context.

Prototype · illustrative data. All names, addresses and amounts are fictitious, and the demo addresses cannot receive funds.
